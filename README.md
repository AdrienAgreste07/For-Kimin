# 🎂 WEB SINH NHẬT BESTIE 🌿

Chào mừng tới với tài liệu hướng dẫn sử dụng "vũ khí tối thượng" để khè nhỏ bạn thân ngày sinh nhật. Web này là sự kết hợp hoàn hảo giữa giao diện hacker ma trận ngầu lòi và vibe sakura/bánh kem cute !

## 📂 1. DANH SÁCH "BẢO VẬT" CẦN CÓ TRONG THƯ MỤC
Để web chạy êm ru, mượt mà không bị lỗi tàng hình, cần gom đủ bộ sậu này để chung vào một thư mục nha:

### 📄 Phần Code (Bộ khung)
* `index.html`: Bộ xương sống của trang web.
* `style.css`: Lớp makeup sương sương, điều chỉnh ánh sáng, hiệu ứng nảy, mờ.
* `script.js`: Bộ não chỉ huy từ nhạc nhẽo, đếm ngược tới pháo giấy đùng đùng.

### 🖼️ Phần Hình Ảnh (Visual)
* `kendu.jpg`: Ảnh xinh xẻo hiện lên lúc đọc lời chúc.
* `kimin.jpg`: Ảnh chốt hạ (lúc chữ nảy lên từng nhịp).
* `banh-kem.gif`: Cái bánh kem lấp lánh (nhớ chọn nền trong suốt/nền đen để khớp với ma trận).
* `avatar.jpg` (hoặc `.jpg`): Cái logo bé tí xíu hiện trên tab trình duyệt (thay cho cái quả địa cầu phèn phèn).

### 🎵 Phần Âm Thanh (Audio)
* `nhac-loi-chuc.mp3`: Nhạc chill chill dạo đầu.
* `nhac-dem-nguoc.mp3`: Nhạc giật gân, kịch tính dội lên lúc màn hình đếm 3-2-1.

## 🚀 2. HƯỚNG DẪN "LÊN ĐỒ" & KIỂM TRA
1. Chắc chắn là tất cả các file ảnh và nhạc đã được đổi tên **Y CHANG** như danh sách ở trên. Sai một dấu gạch ngang `-` hay đuôi file (vd: `.jpeg` thay vì `.jpg`) là nó không hiện đâu nha!
2. Click đúp vào file `index.html` để mở bằng trình duyệt 
3. Nhập mật khẩu: `160507` và ấn `Enter` để test toàn bộ quá trình.

---

## 🛠️ 3. LƯU Ý KHI SỬA CHỮA
* **Muốn đổi mật khẩu?** Mở `script.js`, tìm dòng đầu tiên `const passwordCorrect = "160507";` và thay số khác.
* **Muốn sửa lời chúc?** Mở `script.js`, kéo xuống phần `const messages = [...]` và sửa text trong ngoặc kép. Nhớ đừng xóa nhầm dấu phẩy `,` của người ta nha.
* **Muốn test lại từ đầu trên máy tính?** Hãy ấn tổ hợp phím **`Ctrl + F5`** (ép trình duyệt xóa trí nhớ tạm) rồi mới test.
